Updating the data and adding biographiesThe file works offline with its data embedded. In the HTML source, edit the DATA array to update records. Use Date Shipped and Departure Date for the working timeline dates. Put qualifications about those dates in Uncertainty notes, which appears on the front of the card. A working date can be used even when its exact day remains uncertain. Each spreadsheet row is a separate service record. Add a Biography file field, such as bios/joseph-ellis.html, to load a separate biography on the reverse side. A plain Biography field still works for short text. All populated spreadsheet fields remain available on the card. Uncertain source wording is preserved. Month-only dates span the full month; question marks or “likely” make the date uncertain. Conflicting duplicate shipping dates are flagged.
